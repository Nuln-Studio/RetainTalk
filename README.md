# RetainTalk
本地优先AI记忆持久化陪伴客户端｜Project Digital Immortality (PDI)
* 零阑工坊(Nuln Studio)开发

> 注意：*真正的智能，不是要在虚拟世界里永生，而是认清现实后，依然热爱肉体所感知的温度。*

## 项目说明
基于 Python + pywebview，使用本地文件实现跨会话人格接续记忆持久化，调用智谱GLM‑4‑Flash。

## 仓库说明
本仓库仅存放UI外壳与公开架构文档。
**直接克隆源码无法运行完整PDI记忆功能，完整功能请下载编译后的二进制版本。**
核心记忆、提示词模块为私有闭源实现，仅随二进制分发。
详见 [`不公开的私有模块清单.md`](./py-core/不公开的私有模块清单.md)、[`RetainTalk架构设计-修订精炼版.md`](./RetainTalk架构设计-修订精炼版.md)

## 重要提示
1. 用户全部会话、记忆文件均保存在本地设备。
2. 唯一官方获取渠道为 GitHub Releases，第三方分发不提供安全保障。
3. 仅面向 Windows10及以上 64位平台。
