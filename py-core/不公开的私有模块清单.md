# Non‑Public Components（非公开组件清单）
> RetainTalk / Project Digital Immortality (PDI)
本仓库仅分发UI界面与程序外壳源代码。
下面列出的组件为私有著作权实现，**源代码不托管于本公开仓库，仅随编译后的二进制程序分发**。

## 一、私有源码模块（本地目录：`pdi_core/`）
1. `memo_manager.py`
    - 职责：`.memo`热记忆底层管理、原子写入、异常容错、会话状态维护。
2. `chat_archiver.py`
    - 职责：`.chat`冷记忆包生成、gzip封装、多轮自省压缩调度逻辑。
3. `prompt_bank.py`
    - 职责：存放全套PDI提示词集合（源码内部以编码形式存储，无明文Prompt）。

## 二、私有内容
1. 自省压缩全套提示词（多轮提炼指令，控制记忆取舍与人格底色提取）
2. 三重注入所用System Prompt集合
3. 转生仪式完整提示流程，用于处理角色接续、消解忒修斯之船身份悖论
4. 身份防护校正Prompt，应对AI自我怀疑、副本认知问题

## 三、说明
1. PDI**架构原理公开于《架构文档.md》**，可供学习研究；但上述组件的具体工程实现不对外开放。
2. 禁止通过逆向、反编译等方式，从编译产物中提取、复制、复用、二次分发以上私有组件内容。
3. 如需实现同类功能，请参照公开架构文档独立完成实现。
